# Session Pacing — Productive Dude FULL Claude Tutorial

Source: [FULL Claude Tutorial For Beginners in 2026! (FULL COURSE)](https://www.youtube.com/watch?v=Xg55nTrbYYY) — 1:52:38

Structure: 18 sessions, every minute of the video included. Each session = one coherent chunk a learner watches + practices in one sitting. Roughly 2–12 min of video per session + practice. Order matters; later sessions build on earlier ones.

## Cross-session notes

**Where to slow down:**
- Session 4 (GCAO) — the single highest-leverage segment. Worth running over two sittings if learners struggle.
- Sessions 11–12 (Skills + DBS + first build) — name the pattern, don't push the branded framework.
- Sessions 13–14 (Claude Code foundations + first build) — the densest jump in difficulty. Add a buffer session if needed.

**Branch point: Session 12 → 13.** Non-technical learners can complete the course at Session 12 with everything they need for chat-mode work. Sessions 13–18 are the technical extension — make this a clear opt-in.

**Things the video shows but never teaches** (worth a supplementary session in your own material):
- The decision tree across Skills / Projects / Connectors / Plugins / Artifacts / CLAUDE.md — when to reach for which. The video shows all six and never draws the map. **Strong candidate for your own bonus session between Session 12 and Session 13.**
- Token costs and usage limits — the host hits the Free wall mid-tutorial and swaps accounts without explaining what triggered it.
- Debugging when Claude gets it wrong — every demo in the video "just works." Add a "what to do when it doesn't" lesson, probably after Session 9 or 10.
- Security / blast radius of computer use and "always allow" patterns — flag this in Session 8.
